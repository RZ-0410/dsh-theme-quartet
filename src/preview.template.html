四套皮肤，一套令牌体系

皮肤不重画界面，只换两层东西：设计令牌与会话区底图。前者通过 theme.overrideTokens() 叠在宿主主题之上，后者只是一层背景 CSS，不参与布局。

  • 樱风：藏青与制服红，奶油粉底，细格纹；圆角偏软。
  • 褐东风：青铜与焦褐，云纹铜构；圆角收紧，接近仪表盘。
  • 潮汐：深青与浪白，水平波纹；圆角放大，边缘更松弛。
  • 月壤：月岩灰与星蓝，星点与银晕；圆角最大，留白最多。
client.js
const dispose = ctx.theme.overrideTokens("dsh-theme-quartet", tokens);
ctx.effect(() => dispose, "theme-quartet: 令牌层");

每套色板同时给出 light 与 dark 两个值，跟着宿主明暗自动切换，不需要插件自己判断系统偏好。

底图只在会话滚动区绘制，左侧叠一层随主题走的渐变纱幕：靠文字一侧接近纯色，靠右逐渐透明。侧栏、输入框、代码块仍然是各自的不透明表面，所以长文阅读不受影响。
